# MailAgent AI — client demo

A self-contained presentation demo. Open index.html in a browser, or deploy it as a static site with no build command and publish directory `.`.

Includes owner overview, company creation and branding, editable sample replies, simulated approvals and routing, connection previews and device approval previews. Demo changes are stored in the current browser using localStorage. Reset demo restores the samples.

No real authentication, tenant isolation, passkeys, AI processing, inbox access, background monitoring or email sending is implemented. Do not enter real customer or mailbox information. Workspace IDs do not register domains. Files contain only fictional sample data.

For Render: choose Static Site, no build command, publish directory `.`. The static demo needs no paid compute or database.
